The putting pose — 4 views

Three.js renders of how the user holds the iPhone during the putt, per James's 11-point confirmation 2026-06-03. Right-handed user, both hands on the phone. Long edge of the phone faces the target (= putt-face). Top of phone angled DOWN toward the ground. Back camera lens points at the user's feet / legs. Speakers + lightning port at the bottom point toward the user's chest. Screen visible to the user at a slight angle.

1. Top-down (bird's-eye)

target line runs left → right; user is at the bottom
Shows which long edge of the phone faces the target. The phone is held sideways relative to the user's body, with its long axis roughly perpendicular to the target line. Both hands grip the bottom edge.

2. Behind the user (target-line POV)

looking forward along the target line
Shows the tilt of the phone. Top of phone (camera/notch end) angles DOWN toward the ground — not vertical. The back camera lens (back of phone) faces DOWN-and-toward-user's-feet. The "putt face" (the long edge) is the leading edge pointing at the hole.

3. Side-on (target's view)

target is OUT of the frame to the right
Profile view from the side. You can see the phone's tilt + the user's grip with both hands. The screen faces partially DOWN + toward the user's body.

4. User's near-POV (over-the-shoulder)

slightly behind + above the user
What it looks like over the user's shoulder. Both hands wrapped on the bottom edge of the phone. The screen is angled so the user can see it slightly. Target line clearly along the long edge facing the hole.
